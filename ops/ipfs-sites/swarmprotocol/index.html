SwarmProtocol

The complete specification for defendable AI training data. Tribunal rules. Deed schema. Classification system. Anchoring protocol.

TRIBUNAL
Dual independent base-model judges. 2-pass validation (validate the validator). Drift > 0.15 = flagged. Score-only. Never fine-tuned.
DEED SCHEMA
Five proofs per pair: Origin (who made it), Quality (deterministic score), Process (full lineage), Economics (cost), Trust (Hedera anchor).
CLASSIFICATION
Royal Jelly ≥ 0.85 — production. Honey 0.70–0.84 — improvable. Propolis < 0.70 — intelligence.
SWARMGRAPH
Context graph mapping all decisions. 11 node types, 13 edge types. Any node → full provenance trace.
