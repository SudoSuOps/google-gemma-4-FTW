Certification Process
Seven steps. Client approval at every gate.
Modeled on commercial real estate closing. Nothing moves without sign-off.
01
Intake
Pairs enter the bin queue. Format validated. Fingerprinted. Domain tagged. No scoring yet.
02
Judge A — Pass 1
First base model scores the pair. Reasoning recorded. Score stored. Model: unmodified, deterministic.
03
Judge B — Pass 1
Second base model scores independently. Different model family. Different hardware. Zero shared bias.
04
Pass 2 — Validate
Both judges score again. If drift exceeds 0.15, pair is FLAGGED. No deed issued. This is the tribunal.
05
Deed Issuance
Validated pairs receive title deed with five proofs. Classified: Royal Jelly, Honey, or Propolis.
06
Merkle + Anchor
Batches of 50 deeds → SHA256 Merkle tree → root anchored to Hedera HCS mainnet. Permanent. Public.
Title Premium
Every deed is insured.

What the Premium Covers

Score non-reproducibility — if the deterministic function returns a different score, we re-score the entire batch at no cost
Merkle tree mismatch — if recomputed root doesn't match anchored root, we re-anchor and issue corrected deeds
Judge drift discovered post-issuance — if calibration audit reveals systematic drift, affected deeds are re-scored
Data integrity — if pair fingerprint doesn't match deed fingerprint, full batch review at no cost
Hedera anchor failure — if the consensus timestamp doesn't verify on hashscan, we re-anchor on a new topic sequence
